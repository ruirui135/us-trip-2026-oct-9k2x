まとめ

初海外3人なら、到着LAX（着陸→外に出るまで）は「混雑時は1〜2時間みておく」が安全。降りたら(1)入国審査→(2)預け荷物受取→(3)税関→到着ロビー→Uber/Lyftは専用乗り場「LAX-it」へ、の順です。帰国の10/15は逆に楽な向きで、ラスベガス(LAS)を早朝発の国内線→LAXで成田行きに乗継ぐ流れ。同じユナイテッド1枚の券なら荷物は成田まで通し預け（LAXで受け取り直し不要）の見込みで、LAXでは保安検査も再入国審査もなし。LASは早朝発なので「2時間半〜3時間前」着が安心。時刻・規則は必ず予約前に各自確認を。

到着LAXの全体像（着陸→外に出るまで）と所要時間

国際線が着くのは「トムブラッドリー国際線ターミナル(TBIT＝LAXの国際線専用の建物)」。降りてから外に出るまでの順番は

  • 入国審査(immigration＝パスポートと入国目的を確認する所) →
  • 預け荷物の受取(baggage claim) →
  • 税関(customs＝持込み品の申告) →
  • 到着ロビー、です。目安は全体で30分〜2時間、混む時間帯は2時間以上になることも。とくに国際線が集中する朝6〜9時(アジア便の到着が重なる)は混みやすい。今回の到着は10/8の昼〜午後で、この朝ピークは外れる可能性が高いですが、初海外3人は『最低1〜2時間かかるつもり』で、その後の予定を詰め込みすぎないのが安全です。

📚 出典: lax-international-airport.com・sanspotter.com・flightqueue.com

入国審査：3人は『初海外＝初入国』なので自動端末はAPCキオスク（MPCアプリは使えない想定）

日本人がビザなしで観光する時は ESTA(エスタ＝渡航前にネットで取る入国許可) が必要で、これは別途必須(到着空港で取るものではない)。LAXのTBITには『APCキオスク』という自動端末があり、ESTAを持つビザ免除国の旅行者も使えて、パスポート読取り・顔写真・税関と簡単な質問・指紋を1〜2分ほどで済ませられ、混雑時の待ちが短縮できます(2026年も稼働中)。注意点：スマホで完結する『MPC(モバイル・パスポート・コントロール)』アプリは無料・事前承認不要で便利ですが、対象は米国市民・永住者・一部カナダ人と『ESTAで“再入国”する旅行者(returning VWP)』に限られます。つまり“初めての米国入国”だと使えません。なので3人は基本『APCキオスク or 審査官の窓口』を想定し、初回は指紋採取がある前提で。英語が不安でも端末は日本語表示を選べ、画面の指示どおり進めばOK。質問は『観光/Vacation』『滞在日数』『泊まる所(ホテル名)』程度。

📚 出典: cbp.gov・cbp.gov・en.wikipedia.org

税関の申告書：紙は不要なことが多い／同行家族でなければ各自で

税関で出す『税関申告書(CBP Form 6059B＝持込み品の申告)』は、APCキオスクで電子的に答えるので紙の記入が要らないことが多い。1枚を家族でまとめて出せるのは“同居の家族”が前提なので、友人同士の3人は基本それぞれ申告すると考えておくと安心(キオスクは家族単位での操作が基本で、友人同士は各自操作になる場合が多い)。申告で迷いがちなのは『食品(お菓子・カップ麺等)』『現金1万ドル超の持込み』。お菓子類は念のため正直に申告、で大きな問題は普通ありません。最新の運用は変わるので予約・出発前に各自確認を。

📚 出典: cbp.gov・cbp.gov・lax-international-airport.com

到着後の配車(Uber/Lyft)：必ず専用乗り場『LAX-it』へ。ターミナル前では拾えない

LAXでは通常のUber/Lyftはターミナル前で乗れず、『LAX-it(ラックス・イット)』という専用の集合乗り場に行く決まり(2019年から)。場所はターミナル1の隣。行き方は到着階(下の階＝Lower/Arrivals Level)の、バゲージクレーム外側の内側カーブで緑色の『LAX-it』看板を目印に、(a)無料シャトルバス(約5分間隔・乗車後の所要15分程度)に乗る か (b)歩く(国際線TBITからは歩くと遠めなのでシャトル推奨)。現地で『Uberは緑のレーン2〜4、Lyftはピンクのレーン5〜7、タクシーはレーン1』に分かれています。キャッシュレス志向の3人にはアプリ配車が便利。注意：イベント時や夜は待ち時間が出ることがあるので、アプリで車種(料金安め)と到着時刻を見て選ぶ。Uber Black等の上位車種は例外でターミナル前から乗れます。最新の運用は予約・出発前に各自確認を。

📚 出典: flylax.com・uber.com・goenjoyabroad.com・discoverlosangeles.com

帰国(10/15)：LASは早朝発の国内線→『2時間半〜3時間前』着が安心

ラスベガス(LAS=ハリーリード国際空港)は『国内線は2時間前着』が公式の目安。TSA(保安検査)が混むのは朝5〜8時台と夕方4〜7時で、早朝便はちょうど朝の混み始めにかかります。ただし5〜6時台の最初の波の前は待ち時間が短い(0〜5分)時間帯もあります。初海外3人＋荷物預け＋英語不安を考えると、安全側で『2時間半〜3時間前着』が無難。預け荷物がある場合はチェックインカウンターが開く時間も要確認(早朝便は概ね出発2時間前頃から)。LASは公式サイトと館内モニターでTSAの今の待ち時間が見られるので、当日チェックを。※LASは出発ターミナル(T1=主に国内線/T3=国際線等)が保安検査後はつながっていないので、自分の便のターミナルを必ず確認。時刻は予約・出発前に各自確認を。

📚 出典: harryreidairport.com・airporstinsights.com・flightqueue.com

帰国の乗継(LAS→LAX→成田)は“楽な向き”：LAXで再入国審査なし・保安検査なし

帰りはアメリカを『出る』方向なので、行き(到着)とは段取りが逆で簡単。LAXでは米国の入国審査も税関も保安検査も再度受けません(出国スタンプ的な審査は米国にはなく、搭乗ゲートで搭乗手続きするだけ)。LASで一度TSA保安検査を通れば、LAX到着後はそのまま乗継ぎの国際線ゲートへ。Unitedの国内線はLAXではターミナル7/8に着き、成田行き国際線はTBIT(トムブラッドリー)から出ます。T7/T8とTBITは保安検査の中(エアサイド)の連絡通路でつながっており、同一券なら検査をやり直さず移動できます(徒歩でやや距離があるので時間に余裕を)。

📚 出典: onemileatatime.com・upgradedpoints.com

預け荷物の『通し預け(through check)』：同じUnited1枚の券なら成田まで通る見込み

一般論として、1枚のつながった航空券なら、航空会社は『最終目的地(=成田)まで荷物を預ける』のが基本。とくに今回はLAS→LAX→成田が『米国内→国際線(＝アメリカから出る方向)』なので、LASで預けた荷物は成田まで通し＝LAXで受け取り直し不要、の見込み。※『荷物を一度受け取って預け直す』必要があるのは逆向き(海外→アメリカ到着→米国内線)の時で、今回はその逆なので該当しません。ただし券の組み方や当日の運用で例外もあるため、出発前にUnitedアプリや空港カウンターで『荷物は成田まで(to Tokyo Narita)ですか?』と必ず確認を。荷物タグの行き先(NRT)を自分の目で確認すると安心。

📚 出典: united.com・solotravellerapp.com

LAXでの乗継時間の考え方（帰りの国内→国際）

LAXの『最低乗継時間(これ以下だと航空会社が売らないギリギリの数字)』は国内→国際で概ね45分〜1時間とされます。ただしこれはあくまで最低基準で、専門家は余裕をみて『搭乗券を既に持っていれば2時間、荷物預けやトラブル対応が要るなら2.5〜3時間』を推奨。今回は通し預けなら荷物作業は不要で、保安検査も行き(LAS)で済ませているので不要。それでもターミナル間の徒歩移動があるため、券面の乗継時間が2時間以上あると安心です。1時間台だと国内線(LAS→LAX)が少し遅れただけで危ういので、予約時に乗継時間を確認しておくのがおすすめ。

📚 出典: sanspotter.com・travelcodex.com・airssist.com

成田着(10/16 16時頃)の最後の段取り＝そこで初めて日本の入国・税関

成田に着いたら、米国出国時には無かった『日本の入国審査＋税関』を受けます(ここで荷物を受け取る)。日本入国は『Visit Japan Web(ビジット・ジャパン・ウェブ＝入国/税関を事前にスマホ登録できる公式サービス)』を出発前に登録しておくとスムーズ。2024年1月から入国と税関が1つのQR(2次元コード)にまとまり、さらに2026年は成田・羽田・関西で『Joint Kiosk(ジョイントキオスク)』という端末が導入され、パスポートとQRを1台でかざせば入国と税関を一度に処理できます。無料・初心者でも数分。岡崎さんのカード事情(アメックスのみ)とは無関係で、3人とも各自登録を。※入国だけ登録して税関を忘れるとQRが無効＝紙の申告になるので、両方完了させること。詳細・最新仕様は出発前に各自確認を。

📚 出典: services.digital.go.jp・vjw.digital.go.jp・customs.go.jp

(3) チップ（賭け用の代用貨幣）への両替と、現金化（キャッシュアウト）のやり方

用語：ここでの「チップ」は心づけではなく、賭けに使う円盤状の代用貨幣のこと。

■買い方（現金→チップ）

  • 「ケージ(Cage)」という現金窓口に持って行くと現金に替えてくれる。
  • スロットの場合は、機械から出る『バーコード付きレシート(TITO=チケット・イン/アウト)』を、フロアの自動精算機(キオスク)かケージに入れて現金化。

まず全体像:選択肢は4つ。初心者3人にはどれが現実的か

アメリカでスマホを使う主な方法は4つです。

  • 海外ローミング=日本のSIMのまま現地の電波を借りる方式(ahamoはこれ)。
  • eSIM=スマホに電波情報を書き込む『物理カード不要のSIM』。差し替え不要で設定はスマホ内だけで完結。
  • 現地SIM=アメリカで物理SIMカードを買って差し替える方式。
  • ポケットWi-Fi=小型のWi-Fiルーターを借りて持ち歩く方式。地図・配車(Uber/Lyft)・翻訳(Google翻訳)が中心の使い方なら必要な通信量はそれほど多くなく、岡崎さんは既に ahamo なので『追加料金ゼロ・申し込み不要』のローミングが最有力です。英語がほぼ話せない前提だと、現地SIMは店員との英語のやり取りや英語の設定画面が壁になるので優先度は下がります。

📚 出典: ahamo.com・hanacell.com

本命:ahamo の海外データ通信(岡崎さんは設定オンにするだけ)

ahamoは事前申し込み不要で、海外91の国・地域(アメリカを含む)で『追加料金なし』でデータ通信が使えます。月のデータ量30GB(基本プラン月額2,970円税込)の枠内で海外でも使えるので、追加で払うものは原則ナシ。やることは現地でスマホの『データローミング』をオンにするだけ。物理的な受け取り・返却・差し替えが一切ないのが初心者に最大のメリットです。地図・配車・翻訳・SNS程度なら30GBはかなり余裕があります(動画を長時間見なければ7〜9日で使い切るのは難しいレベル)。同期3人それぞれが ahamo など同様のローミング付きプランなら、全員が同じやり方で済みます。なお『ahamo大盛り(110GB)』に入っていても、海外で使えるのは30GBまでです。

📚 出典: ahamo.com・ahamo.com・faq.ahamo.com

ahamo の3大落とし穴:15日制限・30GB合算・通話/SMSは別料金(着信が高い)

  • 15日ルール:海外で『最初にデータ通信した日(日本時間)』を起算日として15日経過後の0時以降、海外では送受信最大128kbps(地図がほぼ動かないレベルの低速)になります。今回は7泊9日なので15日以内に収まり、ここは問題になりません。
  • 30GBは『日本での利用分と合算』。出発前に日本でたくさん使っていると残りが少ない状態で渡米するので、出発前に残量を確認しておくと安心。
  • 通話・SMSは追加料金なしの対象外で別料金。アメリカ本土での料金は『現地への発信125円/分・日本への発信140円/分・着信(電話を受ける)175円/分』と高め(着信が一番高い点に注意。鳴っただけで出ると課金されます)。SMSは送信1通100円・受信無料。電話したい相手とは LINE通話など『データ通信を使う通話アプリ』を使えば、この高い通話料はかかりません(データ扱いになるため)。

📚 出典: ahamo.com・faq.ahamo.com・nanameue-travel.com

保険・代替案その1:eSIM(日本で買って準備、設定はスマホだけ)

eSIMは『物理カードのいらないSIM』で、出発前に日本で買って、QRコードを読み込む/アプリで開通するだけ。受け取り・返却・差し替えが不要で、ahamoが万一うまく繋がらない時の予備にもなります。アメリカ向けの料金目安(2026年6月時点)は、容量を気にしたくない無制限系なら7日間で約3,300〜4,800円(例:ジャパンコネクトeSIM 約3,280円、Airalo 約3,550円、Holafly 約4,790円)。少なめで安く済ませるなら7日3GBで約1,300〜1,600円、7日10GBで約3,800円前後が目安です。英語が不安なら日本語サポートのある trifa、安さ重視なら Airalo やジャパンコネクトeSIM、無制限の使い放題重視なら Holafly という選び分けが一般的。注意点は『eSIM対応スマホが必須』『開通設定を自分でやる必要がある』こと。心配なら出発前(日本のWi-Fi下)に設定だけ済ませておくと当日慌てません。

📚 出典: japanconnect-esim.store・kakaku.com・trifa.co

代替案その2:ポケットWi-Fi(3人でシェアできるが荷物・受返却が手間)

ポケットWi-Fiは小型ルーターをレンタルし、複数台を同時接続できるので3人でシェアすれば1人あたりは割安になります(アメリカ本土で1日約1,000円前後の例)。日本語の電話サポートがある会社も多く、トラブル時に相談しやすいのも利点。一方デメリットは、

  • 空港カウンターや宅配での受け取り・帰国後の返却が必要、
  • 本体・充電器を持ち歩く荷物になり充電切れに注意、
  • ルーターを持っている人とはぐれると他の人が繋がらない(3人が別行動する場面もある今回のルートでは弱点)。岡崎さんが ahamo を持っている以上、ポケットWi-Fiは『3人とも格安プランで全員ローミング不可』のような場合の選択肢で、今回は優先度は高くありません。

代替案その3:現地SIM(英語が壁。今回は無理に選ばなくてよい)

アメリカに着いてから物理SIMカードを買う方法。料金は割安なこともありますが、英語初心者には壁が多めです。店員とのやり取りやチャージ(残量追加)の説明画面が英語のことが多く、設定でつまずくと『繋がらない→無料Wi-Fiに頼る→セキュリティ不安』という悪循環に陥りがち。また使い切ると一切通信できなくなり、チャージ方法を調べることすらできなくなるリスクも。どうしても現地SIMにしたい場合でも『日本で事前に買っておく(日本語で購入・設定できる)』のが鉄則とされています。今回は ahamo があるので、無理に現地SIMを選ぶ理由は薄いです。

無料Wi-Fi(空港・ホテル)の注意:便利だが「ログイン・決済はしない」

空港やホテルの無料Wi-Fiはタダで使えて便利ですが、リスクが2つあります。

  • 通信が暗号化されていないと、入力した内容(IDやパスワード)を盗み見られる恐れ。
  • 正規そっくりの名前の『偽物Wi-Fi(なりすまし。別名・悪魔の双子)』に誤って繋ぐと情報を抜かれる危険。対策は、(a)スマホの『Wi-Fi自動接続』を旅行前にオフにする、(b)銀行・クレジットカード・重要なログインは無料Wi-Fiでやらず、自分の回線(ahamo/eSIM)で行う、(c)接続名はスタッフに正しい名前を確認してから繋ぐ、(d)サイトのアドレスが鍵マーク付きのhttpsかを見る、(e)心配ならVPN(通信を暗号化して盗み見を防ぐアプリ)を使う。キャッシュレス志向で決済アプリやカードを使う場面が多いはずなので、『決済・ログインは無料Wi-Fiでやらない』を3人の共通ルールにしておくと安全です。
