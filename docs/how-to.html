つかいかた｜スプレッドシートでみんなで編集する

💡
このページは

しおりの「プラン（日程・未決事項）」を、参加者みんなでGoogleスプレッドシートから編集するためのやり方です。 コードやGitHubの知識は要りません。スプレッドシートを直すだけ。 直した内容は、岡崎さんがサイトを再成形したときに反映されます。

目次

① 全体の流れ

このしおりは、こういうループで「いつも最新」を保ちます。

✅

大事な分担：スプシの編集は3人みんな。サイトの再成形（作り直し）は岡崎さん×Claude。 だから他の2人はGitHubもClaudeも触らなくてOK。

② 参加者向け：編集のルール

開くタブは2つだけ。あとは自由に書き込み・行追加してOKです。

「日程」タブ
時刻・場所・宿・予約状況・メモを編集。予定が増えたら行を足す。決まってない時刻は空欄でOK。
「未決事項」タブ
まだ決まってないこと（★）の一覧。決まったら 状態 を「未着手→相談中→決定」に変え、決定内容 に結論を書く。
⚠️
これだけ守ってください
  1. タブの名前を変えない（「日程」「未決事項」のまま）。
  2. 各タブの1行目（見出し）を消さない・並べ替えない。列を増やすのはOK。
  3. パスポート番号・カード番号・自宅住所など、人に見られて困る情報は書かない（サイトは「リンクを知っている人は見られる」公開設定のため）。

※ ①②は、サイトが「タブ名」と「見出し名」を目印にデータを読むため。ここが変わると読めなくなります（gidで多少守ってありますが、念のため）。

③ 岡崎さん向け：最初の1回だけの準備

ここは岡崎さんが一度だけやる作業です。終わったら、あとは「ふだんの運用」だけ。

  1. テンプレをGoogleスプレッドシートに取り込む
    旅行データ_テンプレート.xlsx を Googleドライブにアップ → 右クリック「アプリで開く → Googleスプレッドシート」。これで「つかいかた／日程／未決事項」の3タブができます。
  2. 3人を編集者に招待＋全体を「閲覧可」に
    右上「共有」→ 大野さん・千葉さんのGmailを追加して権限を「編集者」に。 さらに「一般的なアクセス」を「リンクを知っている全員：閲覧者」にする。
    → こうすると「編集できるのは3人だけ／サイトは誰でも読める」という安全な組み合わせになります。
  3. 更新メール（通知）をオンにする
    メニュー「ツール → 通知設定（通知ルール）」→「変更が行われたとき」→「メール - 1日1回のまとめ」を選んで保存。 → 誰かが編集した日に、岡崎さんへメールが届きます。
  4. スプレッドシートの「ID」と各タブの「gid」をClaudeに渡す
    ブラウザのURLが、こういう形になっています。色の付いた2か所を伝えればOK：
    スプレッドシートのURL 
    https://docs.google.com/spreadsheets/d/{ここがID}/edit#gid={ここがgid}
    「日程」タブを開いているときのgidと、「未決事項」タブを開いているときのgidは別物です。各タブを開いてURL末尾の gid=… をそれぞれ控えてください。
  5. Claudeが配線して公開
    受け取ったID/gidをサイトの再成形処理に設定し、最新データを焼き込んで GitHub Pages に公開。URL1つを3人に共有して完成。

④ ふだんの運用

  1. 誰かがスプシを編集する（3人の誰でも）。
  2. その日、岡崎さんに通知メールが届く。
  3. 岡崎さんがClaudeに 「サイト更新して」 と頼む。
  4. Claudeがスプシを読み直して再成形→公開。数十秒〜数分で最新版に。
  5. 全員、同じURLをリロードすれば最新が見える。
🔁

「更新はこまめに / 再成形はまとめて」でOK。毎回の編集ごとに作り直す必要はありません。出発が近づいたら頻度を上げましょう。

⑤ よくある質問

サイトは「再成形」したときの内容で固定されています。岡崎さんがClaudeに「サイト更新して」と頼んで作り直すと反映されます。直しただけでは自動では変わりません（これは仕様です）。
元の名前（日程／未決事項）に戻せばOK。タブの中身（gid）を目印にしているので多くの場合は耐えますが、念のため名前は変えないのが安全です。
増やすのは自由です（サイトは見出し名で読むため）。ただし既存の見出しは消さない・名前を変えないでください。新しい列をサイトに表示したいときは、岡崎さん経由でClaudeに伝えてください。
「共有」からその人のGmailを「編集者」で追加すればOK。サイト側の設定変更は不要です。
このスプシ／サイトには書かないでください。サイトは「リンクを知っている人は見られる」公開状態です。お金や本人確認の情報は、LINE等の身内だけのやり取りで共有を。

⑥ 用語ミニ辞典

再成形（さいせいけい）
スプレッドシートの最新データを読んで、サイトを作り直すこと。岡崎さん×Claudeが行う。
gid（ジー・アイ・ディー）
スプレッドシートの「タブ1枚ごとの番号」。URLの末尾 gid=… に出る。タブ名を変えても番号は変わらないので、目印に使う。
閲覧者／編集者
Google共有の権限。閲覧者＝見るだけ、編集者＝書き込める。今回は「全体は閲覧者・3人だけ編集者」。
GitHub Pages
GitHubが無料でサイトを公開してくれる仕組み。タスクスライムで使ったのと同じ。URL1つで全員に共有できる。
